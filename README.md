# HYBRID PETCRETE

## Project Title
Development and Performance Evaluation of Hybrid PET Fiber-Reinforced
Concrete Using Recycled Coarse Aggregate.

## Team Name
ATS BOYZ

## Project Overview
This project investigates the use of recycled PET bottle fibers and
recycled coarse aggregates in concrete to explore sustainable
construction materials.

## Objectives
- Reduce PET plastic waste through reuse.
- Conserve natural coarse aggregates.
- Evaluate concrete workability and mechanical properties.
- Study compressive, split tensile, and flexural performance.
- Assess water absorption and material consistency.
